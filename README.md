# 🏙️ CityPulse

> **Know what's happening around you.**

![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)
![React](https://img.shields.io/badge/React-18.x-blue.svg)
![TailwindCSS](https://img.shields.io/badge/Tailwind-CSS-38B2AC.svg)

CityPulse is a comprehensive civic dashboard designed to keep residents informed, engaged, and connected with their local community. Whether you're looking for real-time local updates, community events, or civic data, CityPulse brings the heartbeat of your city right to your screen.

## ✨ Features

- **Real-Time Updates:** Stay in the loop with the latest news, announcements, and alerts from your local area.
- **Civic Dashboard:** An intuitive, at-a-glance view of essential city metrics and public services.
- **Community Events:** Discover what's happening around you with an up-to-date schedule of local gatherings and meetings.
- **Responsive Design:** Built with a mobile-first approach, ensuring a seamless experience across all devices (desktop, tablet, and mobile).

## 🚀 Tech Stack

- **Frontend:** React, Vite
- **Styling:** Tailwind CSS
- **Deployment:** Bolt.new

## 🛠️ Getting Started

To run this project locally, follow these steps:

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/deepikayadav12009-creator/citypulse-civic-dash.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd citypulse-civic-dash
   ```

3. **Install the dependencies:**
   ```bash
   npm install
   ```

4. **Start the development server:**
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:5173` to view the app!
